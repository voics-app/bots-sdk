# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); releases and entries are generated by release-please from Conventional Commits.

## 0.1.0 (unreleased)

### Features

- Gateway `Client`: P7 protocol, intents, heartbeat with zombie detection, resume, re-identify, reconnect with exponential backoff, a send budget of 120 frames per 60 seconds, and a typed event emitter.
- `RestClient`: `Authorization: Bot <token>`, per-bucket queues driven by the `X-RateLimit-*` headers, retries for global and bucket 429s and transient 5xx responses, and `DiscordyApiError`.
- `Routes` for every P9 endpoint, and `DiscordyApi` typed helpers.
- Builders for slash commands (options, subcommands, groups, default permissions, contexts), context menus, buttons, selects, modals and embeds, all validated against Discord's limits.
- `InteractionRouter` with `reply`, `deferReply`, `editReply`, `followUp`, `update`, `deferUpdate`, `showModal` and autocomplete.
- `WebhookClient`, a `Permissions` helper with Discord's permission computation, `Intents`, snowflake helpers and `buildInviteUrl`.
- `examples/moderation-bot` with `/ping`, `/kick` (confirmation buttons) and `/purge`.
