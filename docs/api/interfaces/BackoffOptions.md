# Interface: BackoffOptions

## Properties

### baseMs

> **baseMs**: `number`

Delay of the first retry in milliseconds.

***

### jitter

> **jitter**: `number`

Fraction (0..1) of the delay that random jitter may remove.

***

### maxMs

> **maxMs**: `number`

Upper bound for any delay in milliseconds.
